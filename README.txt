چاچی (Native) — راهنما
=========================

این پوشه، سورس‌کد کامل نسخه‌ی native اندروید چاچیه (با Flutter). خودت لازم نیست
چیزی رو کامپایل کنی — یه فایل به اسم .github/workflows/build-apk.yml داخلشه که
باعث می‌شه GitHub خودش، به‌صورت خودکار، یه پروژه‌ی اندروید تازه بسازه، کد این
پوشه رو روش سوار کنه، و در آخر یه فایل APK آماده تحویلت بده — بدون نیاز به
Android Studio یا نصب چیزی رو سیستم خودت.

مراحل:
1) یه ریپازیتوری جدید توی گیت‌هاب بساز (مثلاً chachi-native).
2) تمام محتوای این پوشه (لیست کامل زیر) رو توش آپلود کن — دقیقاً با همین
   ساختار پوشه‌ها (خیلی مهمه که پوشه‌ی .github و زیرپوشه‌هاش دقیقاً حفظ بشه؛
   چون گیت‌هاب پوشه‌های نقطه‌دار رو موقع drag & drop معمولی گاهی مخفی نشون
   می‌ده — بهتره برای این مرحله از "git" واقعی یا از حالت "Add file → Create
   new file" برای build-apk.yml استفاده کنی و مسیر کامل
   .github/workflows/build-apk.yml رو تایپ کنی).
3) بعد از Commit، برو به تب "Actions" بالای صفحه‌ی ریپو. یه ورک‌فلو به اسم
   "Build Chachi APK" می‌بینی که خودش شروع به اجرا می‌کنه (چند دقیقه طول
   می‌کشه).
4) وقتی تیک سبز خورد، روی همون اجرا کلیک کن، پایین صفحه بخش "Artifacts" رو
   پیدا کن، و فایل "chachi-apk" رو دانلود کن — یه zip هست که فایل
   app-release.apk توشه.
5) اون APK رو منتقل کن رو گوشی اندرویدت (از طریق تلگرام به خودت، گوگل درایو،
   یا کابل) و نصبش کن. اندروید احتمالاً هشدار «از منبع ناشناس» می‌ده — چون از
   گوگل‌پلی نیومده، طبیعیه؛ اجازه‌ی نصب رو بده.

نکات مهم و صادقانه:
- این‌بار چون Gradle و تنظیمات اندروید رو خودِ GitHub Actions، لحظه‌ی build
  از صفر می‌سازه (نه من از قبل دستی نوشته باشمش)، احتمال خطاهای ناسازگاری
  نسخه که دفعه‌ی قبل اذیتت کرد خیلی کمتره. اگه بازم Actions قرمز شد (failed)،
  روی اجرا کلیک کن، لاگ رو باز کن، و اسکرین‌شات همون خط قرمز رو برام بفرست —
  چون اونجا خطای دقیق فنی رو نشون می‌ده و راحت‌تر از خطاهای گنگ VSCode
  قابل رفعه.
- یادآورهای «ساعت مشخص» با سیستم زمان‌بندی خود اندروید کار می‌کنن و حتی بعد
  از ریستارت گوشی هم باقی می‌مونن — نیازی به باز نگه‌داشتن اپ نیست.
- یادآورهای «تکرار فاصله‌ای» از قبل برای چند روز آینده زمان‌بندی می‌شن (بسته
  به اینکه فاصله‌شون چقدره) و هر بار که اپ رو باز کنی، این بازه دوباره جلوتر
  کشیده می‌شه. برای بهترین نتیجه، سعی کن چاچی رو حداقل هر چند روز یه‌بار باز
  کنی تا زمان‌بندی‌ها همیشه به‌روز بمونن.
- صدای نوتیف الان یه صدای ملایم اختصاصیه که خودم ساختم (نه دقیقاً Meteor، به
  خاطر کپی‌رایت) — ولی چون این‌بار native هست، اگه یه فایل صوتی دلخواه دیگه
  (غیر از تن‌های اختصاصی سامسونگ) داشته باشی، می‌تونم جایگزینش کنم.
- آیکون کوچیک بالای نوار وضعیت گوشی (status bar) طبق قانون خود اندروید فقط
  به‌صورت یه شکل تک‌رنگ (سفید) نمایش داده می‌شه، نه نسخه‌ی رنگی مسکاتِ چاچی؛
  این محدودیت سیستم‌عامله برای همه‌ی اپ‌ها، نه مشکل این اپ.
